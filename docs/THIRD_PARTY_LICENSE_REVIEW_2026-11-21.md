# AOL website third-party licence review

Review date: 21 November 2026

This record covers the material third-party assets and libraries intentionally used by the AOL Accountants website. It is an internal compliance record, not public marketing copy and not a legal opinion.

## Approved photograph

- Asset: Microsoft 365 photograph `oUbzU87d1Gc` on Unsplash
- Official source: https://unsplash.com/photos/a-person-sitting-at-a-table-with-a-laptop-oUbzU87d1Gc
- Licence: https://unsplash.com/license
- Result: the Unsplash License permits free commercial website use without separate permission or mandatory attribution.
- Controls: retain the source and creator record; do not sell the image as a standalone unmodified file; do not compile it into a competing image service; do not imply endorsement by Microsoft 365 or Unsplash.
- Image review: the source contains a partial face at its lower edge. The public mobile and desktop presentations crop that area out, and the uncropped source is retained internally rather than copied into the public build. No recognisable individual is presented as endorsing AOL Accountants.

## Owner-provided AOL logo

- Classification: owner-provided and owner-authorised AOL brand asset.
- Control: use only for the AOL Accountants website and associated AOL materials; do not redistribute it as a stock or reusable third-party asset.

## Fonts

- Manrope: SIL Open Font License 1.1. Official Google Fonts licence record: https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt
- Spectral: SIL Open Font License 1.1. Official project record: https://github.com/googlefonts/spectral
- Use: self-hosted web-font subsets generated by Next.js. No font files are sold separately and no reserved font names are used for modified fonts.

## Icons

- Lucide: ISC License. Official project licence: https://github.com/lucide-icons/lucide/blob/main/LICENSE
- Use: interface icons only; no Lucide brand logos or implied endorsement.

## Application libraries

- React: MIT License. Official licence: https://github.com/facebook/react/blob/main/LICENSE
- Next.js: MIT License. Official licence: https://github.com/vercel/next.js/blob/canary/license.md
- The source repository retains the dependency licence files installed with the packages.

## Release conclusion

The documented use is consistent with the stated commercial-use permissions of the reviewed licences. The website must continue to preserve source records, avoid false endorsements, and avoid redistributing licensed assets as standalone products. Any future photograph, font, icon set, template or code package requires its own source and licence entry before release.
